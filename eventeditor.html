How it works

  1. Pick your event above. The editor loads its data file from _data/events on GitHub.
  2. Edit it on the Form tab, or change the YAML directly. Problems show on the right as you type.
  3. Preview the event page built with the site's own page templates.
  4. Save it: download the file, copy the YAML, or commit it to a branch on GitHub and open a pull request.

Nothing changes on the site until a pull request is merged. Step by step instructions are in the event data editor documentation.
