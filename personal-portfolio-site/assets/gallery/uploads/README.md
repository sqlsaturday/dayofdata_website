# Upload all event photos here — one folder

This is the ONLY folder you need to use to add new public speaking, audience, conference, meetup and community photos to Mourakshit.com.

### Steps
1. Open this GitHub folder.
2. Click **Add file → Upload files** and drag in your JPG, JPEG, PNG or WebP pictures.
3. Choose **Commit changes** on `main`.
4. New pictures will be discovered by the homepage slideshow and the Gallery page after the website deployment updates.

### Optional automatic grouping by event
Filename format: `YYYY-MM-DD__event-name__description.jpg`.

Examples:
- `2026-10-22__southfield-genie__presenting.jpg`
- `2026-09-12__day-of-data-detroit__audience.jpg`
- `2026-10-30__mitechcon__session-room.jpg`
- `2026-09-29__fabcon-barcelona__exhibition-hall.jpg`

If you do not rename the files, they still appear automatically under **New uploads**. Filenames are interpreted only as display captions; avoid sharing confidential photos. The site uses `object-fit: contain` to preserve aspect ratios, and does not stretch/crop the originals.

### Important
- The gallery shows only verified existing event images and the new images that you upload. No synthesized audience photos.
- High-resolution originals are best, but keep individual files reasonably sized for fast mobile loading (ideally under ~3 MB each).
- Remove duplicates and photos with people who have not consented to public posting.
- Keep this README in the folder.
